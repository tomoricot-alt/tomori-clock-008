# 開発レポート：TOMORI CLOCK (APP 008)

## 実装内容
- Expo SDK 57 / React Native 0.86 / TypeScript / React Native Web。追加した実行時ライブラリは時計描画用の `react-native-svg` のみ（Expo公式対応でiPhone・Web共通）。テストは `vitest`（開発時のみ）。
- 計算ロジックは画面から分離（`src/logic/`）。
  - `clock.ts`: 時刻を「12:00からの経過分(0〜719)」で保持。長針=分×6°、短針=経過分×0.5°（分に合わせて少しずつ動く）。剰余計算のため 11:59→12:00 も正確。デジタル表示・よみがな、ドラッグ角度→時刻変換（59→0分で時も進む/戻る）。
  - `quiz.ts`: 出題（入門=5分単位/チャレンジ=1分単位、10問、時刻の重複なし、4択は「時と分の取りちがえ」「1時間ずれ」「分のずれ」を含む）、判定（完全一致のみ正解）、集計。
  - `storage.ts`: localStorage への保存（最大30件、壊れたデータは無視、使えない環境ではメモリ保存）。
- 画面: ホーム／みてみよう／じこくを つくろう／クイズ10もん＋結果／きろく。針は指・マウスでドラッグでき、「じ」「ふん」の大きな＋−ボタンでも操作可能。
- デザイン: 白基調、青・オレンジ。短針=オレンジ・太く短い、長針=青・細く長い。ボタン高さ64px以上。難しい漢字はひらがな表記。
- 一覧サイト連携: `app-info.json`（id 008）を作成。`tomori-app-lab` の `templates/app-template` を参照（下記の注意参照）。公開用ワークフロー・検証スクリプトもテンプレートのものを使用。

## 未確認・制限事項
- **実機 iPhone での確認は未実施**（エミュレーションのみ）。Safari での針ドラッグ・スクロール抑止（`touch-action: none`）は実機確認が望ましい。
- **GitHub Pages への公開はマージ後に確認が必要**（初回のみ Settings → Pages → Source を「GitHub Actions」に設定）。
- 学習結果の保存は `localStorage`（Web）が対象。ネイティブ(Expo Go等)では追加ライブラリを増やさない方針のため、アプリ再起動で消えるメモリ保存にフォールバックする。公開はWebのみの想定。
- 一覧サイトの自動化PR #2 は、作業時点では `main` に**未マージ**だった。そのため PR のブランチ `claude/modest-goodall-azmqsq` の `templates/app-template` を参照した。マージ時にテンプレートが変わっていないか確認してほしい。
- Expo の `npx expo install` は環境の通信制限で互換性取得ができず、`expo` 同梱の `bundledNativeModules.json` に従ってバージョンを指定した。
- `npm audit` に開発ツール由来の指摘が出ているが、アプリは外部通信・個人情報の取得を行わない。
