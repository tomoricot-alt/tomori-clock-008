# TOMORI CLOCK の使い方

アナログ時計を見ながら、時刻の読み方を練習するアプリです。小学3・4年生向けです。

## 1. 最初にすること
1. ホームの「モードを えらぼう」で、どちらかを選びます。
   - **にゅうもん**: 5分きざみの時刻（3:05、3:10 …）。時計のふちに「5・10・15…」の数字が出ます。
   - **チャレンジ**: 1分きざみの時刻（3:07 など）。
2. 下のボタンから、やりたいことを選びます。

## 2. みてみよう（れんしゅう）
1. はりを指でなぞって動かします。動かしにくいときは、下の大きなボタンを押します。
   - 「−1じ」「＋1じ」: みじかい はり（オレンジ）の「じ」を変える
   - 「−ふん」「＋ふん」: ながい はり（あお）の「ふん」を変える
2. 画面の上の **デジタル表示**（例: 2:30）と、はりの形をくらべます。
3. 「ちょうど」「はん」ボタンで、0分・30分にすぐ合わせられます。
- 長針が1周（60分）すると、短針は1目盛り（1時間）進みます。30分のときは、短針が2つの数字のまん中にあります。
- 11:59 の1分後は 12:00 です。

## 3. クイズ 10もん
1. 「クイズ 10もん」を押します。
2. **時計を読む問題**: 時計を見て、4つの時刻から正しいものを選びます。
3. **時刻を作る問題**（3・6・9問目）: 出された時刻になるように、はりを動かして「これで こたえる」を押します。
4. ⭕ か ❌ が出ます。まちがえたときは、正しい答えが表示されます。「つぎへ」で進みます。
5. 10問が終わると、点数・せいかいりつ・まちがえた問題が出ます。結果は自動で保存されます。

## 4. じこくを つくろう
出された時刻になるように、はりを動かす練習です。何回でもできます（記録には残りません）。

## 5. きろく
モードごとの「いちばんよかった点数」と「さいきんの10回」を見られます。「きろくを けす」で消せます（確認のため2回押します）。

## ⚠️ 大事なこと
- きろくは**このスマホ／パソコンのブラウザの中だけ**に保存されます。
- ブラウザの「閲覧データの削除」をすると**きろくが消えます**。
- 別の端末や別のブラウザでは同じきろくは見られません。
- 名前・学校名・メールアドレスなどは入力しないでください（求められることもありません）。
